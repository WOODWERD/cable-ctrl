# Changelog

Newest first. Versions are public betas until A1.0.0.

## x0.0.6 — 2026-11-16

- Any hex colour works in the Colour column, including short ones like #F00.
- A different colour on the same type now starts a new type, such as USB Blue, instead of being ignored.
- A colour with no type joins the type that already has that colour, or starts a new type named after it. It never changes Other.

## x0.0.5 — 2026-11-16

- The spreadsheet template has an optional Colour column. Give a palette name, such as Blue, or a hex colour, such as #3A93C9, and it sets that type's colour for every label of the type.
- Before you add a spreadsheet, the summary shows the colour each new or changed type will take.
- A colour the app can't read doesn't drop the row. The label still comes in, and the summary names the row.

## x0.0.4 — 2026-11-01

- Cable Ctrl's offline copy no longer clears the offline copies of other WOODWERD tools.
- Since then: the All WOODWERD tools menu gained new tools, the GitHub button and the WW button icons.

## x0.0.3 — 2026-11-01

- The user guide opens with a Printer required notice for the Liene PixCut S1.

## x0.0.2 — 2026-11-01

- The header and Label Print name the tested printer, the Liene PixCut S1, with links to Liene's pages.

## x0.0.1 — 2026-11-01

- First public beta.
